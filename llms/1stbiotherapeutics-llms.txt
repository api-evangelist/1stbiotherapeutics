# 1ST Biotherapeutics

> 1ST Biotherapeutics (1STBIO) is a clinical-stage biopharmaceutical company founded in 2016 and
> headquartered in Gyeonggi-do, South Korea. It discovers and develops novel small-molecule
> therapeutics for areas of significant unmet medical need — neurodegenerative disease,
> immuno-oncology, metabolic disease and rare/orphan disease — supported by a genomics-based
> target discovery capability.

## Machine-readable API surface

**1ST Biotherapeutics publishes no API.** As of 2026-09-05 the company operates no developer
program, no developer portal, no SDK, and no machine-readable contract of any kind. This was
established by probe, not by assumption:

- No OpenAPI, Swagger, GraphQL SDL, AsyncAPI or MCP surface on any host the company controls.
- No `api.`, `developer.`, `docs.`, `dev.` or `portal.` subdomain of `1stbio.com` resolves in DNS.
- Every `/.well-known/` discovery path probed on `1stbio.com` and `www.1stbio.com` returned 404
  (see `well-known/1stbiotherapeutics-well-known.yml` for the full probe record).
- The corporate site is an eight-page WordPress install on WP Engine. Its `/wp-json` endpoint
  serves the stock WordPress REST API discovery document (namespaces `wp/v2`, `oembed/1.0`,
  `yoast/v1`, `gravityforms/v2`, `wpe/cache-plugin/v1`). That is default CMS infrastructure that
  ships with WordPress, not a product API this company designed, documented or supports, so it is
  deliberately NOT catalogued as an API of 1ST Biotherapeutics.

If you are an agent looking for a callable 1ST Biotherapeutics API, there is not one to call.
